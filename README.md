# Assets Browser

Каталог игровых ассетов с фильтрами по тегам, карточками с описаниями и экспортом выбранных позиций в Markdown.

[Открыть галерею](https://yankonopelko.github.io/assets-browser/)

Сайт публикуется на GitHub Pages из папки `docs`. В карточках есть ссылки на Unity Asset Store и посты в Telegram. Для открытия поста нужен доступ к соответствующей теме.

## Локальная проверка

Откройте [docs/index.html](docs/index.html) в браузере. Галерея запускается
напрямую из файла с текущей подборкой ассетов.

1. Проверьте, что на карточках загрузились превью, названия и теги.
2. Выберите «Окружение» и «URP». В тестовой подборке останется City Adventure.
   Кнопка «Все ассеты» сбрасывает фильтры.
3. Нажмите карточку. Должны открыться полное описание и ссылки на пост в Telegram
   и Unity Asset Store, если он указан для ассета.
4. Отметьте пару карточек кнопкой «+» и переключите фильтры. Счётчик «Экспорт»
   должен сохранить выбор. Нажмите «Экспорт» и откройте скачанный
   `selected-assets.md`. В нём должны быть только отмеченные ассеты с их ссылками.
   Снимите отметки и убедитесь, что кнопка экспорта скрылась.

Автоматическая проверка галереи в установленном Edge или Chrome запускается
из корня репозитория.

```powershell
python tests/check_gallery.py
```

Скрипт использует временный профиль браузера и локальный HTTP-сервер. Если браузер
установлен в другом месте, передайте путь к его исполняемому файлу через
`--browser`. Скрипт проверяет сформированное содержимое экспорта. Скачивание
файла можно проверить по шагу 4.
